# Welcome to starter-repo2

This is the documentation for the starter-repo2 Python package.

## Quick Start

```powershell
# Install the package
python -m pip install -e .

# Run tests
python -m pytest
```

```
├── src/           # Source code
│   └── starter_repo2/

```
