## Quick Start

1. Clone the repository:
```powershell
git clone https://github.com/cphelps34/starter-repo2.git
Set-Location C:\Repos\starter-repo2
```

2. Set up Python environment:
```powershell
python -m venv .venv
& .\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip setuptools wheel
python -m pip install -e .
python -m pip install pytest
```

3. Run tests:
```powershell
python -m pytest -q
```

## Recent changes (Nov 8-9, 2025)

The data preparation pipeline was improved and documented. Key changes pushed to GitHub:

- Added/updated data-prep scripts (location: `src/analytics_project/data_prep`):
    - `customer_data_prepared.py` — cleaned and standardized customer data.
    - `product_data_prepared.py` — cleaned and standardized product data.
    - `sales_data_prepared.py` — completed sales cleaning pipeline with:
        - Customer/Product ID format standardization for cross-file validation
        - Robust missing-value handling (treats `?`, empty strings, commas)
        - Outlier removal using IQR (protected against empty inputs)
        - Date and numeric field standardization and error handling
        - Duplicate removal using `TransactionID`

- Added processed data file:
    - `Data/Processed/sales_data_cleaned.csv` (generated by `sales_data_prepared.py`)

- Removed unused package entrypoints previously under `src/starter_repo2/`.

## How to run the data preparation

From the repository root (PowerShell):

```powershell
Set-Location C:\Repos\starter-repo2\src\analytics_project\data_prep
python sales_data_prepared.py
# Output written to: ..\..\..\Data\Processed\sales_data_cleaned.csv
```

Notes:
- The sales script reads raw CSVs in `Data/Raw/` and expects cleaned customer/product references in `Data/Processed/` when available; it falls back to using IDs present in the sales file when references are missing.
- The scripts include defensive checks for malformed numeric/date fields and will fill missing values with safe defaults so downstream analysis can proceed.
